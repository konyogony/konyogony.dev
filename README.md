# hypr.konyogony.dev

A browser-based terminal emulator UI for Hyprland, built with Next.js 16, React 19, TypeScript, and Tailwind CSS.

## Architecture

| Component | Technology | Hosting |
|-----------|------------|---------|
| Frontend  | Next.js (static export) | GitHub Pages |
| Backend   | Rust | Oracle Cloud |
| Agent     | Rust | Oracle Cloud |

## Deployment

### GitHub Pages (frontend)

The frontend is deployed as a **fully static site** to GitHub Pages at [hypr.konyogony.dev](https://hypr.konyogony.dev).

**Deployment trigger:** Automatic on every push to `main` (production-only, no preview deployments). Manual dispatch is also available via the Actions tab.

**Build output:** `frontend/out/` — generated by `next build` with `output: 'export'`.

#### SSR / API compatibility

No server-side rendering or API routes are used. The app is a purely client-side React application:

- ✅ No `getServerSideProps`
- ✅ No `app/api/*` route handlers
- ✅ No `pages/api/*` routes
- ✅ Already configured with `output: 'export'` in `next.config.ts`
- ✅ Images set to `unoptimized: true` (required for static export)

#### One-time GitHub repository settings

1. Go to **Settings → Pages**.
2. Set **Source** to **GitHub Actions**.
3. Under **Custom domain**, enter `hypr.konyogony.dev` and save.
4. Ensure your DNS provider has a `CNAME` record pointing `hypr.konyogony.dev` → `<your-github-username>.github.io`.

A `CNAME` file containing `hypr.konyogony.dev` is included in `frontend/public/` and will be present in every deployed artifact automatically.

### Backend (Oracle Cloud)

The backend runs independently on Oracle Cloud. When the frontend needs to call the backend, configure the API base URL via a `NEXT_PUBLIC_API_URL` environment variable:

```bash
# .env.local (never committed)
NEXT_PUBLIC_API_URL=https://api.hypr.konyogony.dev
```

Add this as a **repository secret or Actions variable** (`NEXT_PUBLIC_API_URL`) if the build needs it at build time, or configure it in your deployment pipeline.

## Local development

```bash
cd frontend
bun install
bun run dev      # http://localhost:3000 (Turbopack)
bun run build    # produces frontend/out/
bun run lint
```
